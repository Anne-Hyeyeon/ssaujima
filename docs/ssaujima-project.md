# 싸우지마 (ssauji-ma)

> 결혼 전 부부의 생활습관 궁합을 진단하는 서비스

해커톤 프로젝트입니다. 결제 플로우는 목업 수준이면 됩니다.

---

## 📌 프로젝트 한 줄 요약

두 사람의 생활 습관을 64가지 항목으로 진단해서, **다툼 가능성이 높은 부분**과 **잘 맞는 부분**을 AI가 분석해 리포트로 제공하는 서비스.

---

## 🎯 핵심 컨셉

### 문제 정의

- 결혼 후 가장 많이 싸우는 이유는 **성격 차이**가 아니라 **생활 습관 차이**
- 사소한 부분(설거지 타이밍, 청소 빈도, 침대 사용 규칙)에서 매일 부딪힘
- 결혼 전 미리 알면 갈등을 줄일 수 있음

### 차별점

- 다른 커플 매칭 테스트는 성격/취향만 봄
- 우리는 **돈, 양가 가족, 자녀 계획, 디지털·사생활** 같은 민감하지만 진짜 중요한 영역까지 진단
- 이게 핵심 셀링포인트

### 타겟

- 결혼을 앞둔 한국 예비부부
- 결혼한 지 얼마 안 된 신혼부부

## 🏗️ 서비스 구조

### 두 가지 버전

#### 🆓 심플 버전 (무료)

- **15문항**, 2~3분 소요
- **AI 사용 안 함** (룰 기반 계산)
- 즉시 결과 표시 (1초 내)
- 심리테스트 느낌, 바이럴 목적
- 결과: 8가지 유형 분류 + 궁합 점수 + 간단한 잘맞음/부딪힘

#### 💎 프로 버전 (2,900원)

- **64문항**, 7~10분 소요
- **AI 사용** (Claude API 호출)
- 5~10초 분석 로딩 (가치 있어 보이게)
- 맞춤형 조언, PDF 다운로드
- 결과: 11개 영역별 그래프 + 다툼 TOP 5 + 맞춤 조언 + 종합 결론

### 왜 이렇게 분리?

- **비용**: 무료 사용자에게 AI 호출하면 비용 폭탄
- **UX**: 심플은 빠른 결과로 공유 유도, 프로는 로딩 시간으로 가치 어필
- **일관성**: 룰 기반은 같은 답이면 같은 결과 → 친구랑 비교 가능

## 🎨 디자인 시스템

### 디자인 톤

- **노션 + 애플 미니멀 스타일**
- 큰 타이포그래피, 넉넉한 여백
- 캐릭터/일러스트 없음 (타이포 중심)
- 0.5px 라인으로 영역 구분 (박스, 그림자 최소화)
- 한 화면에 한 메시지

### 컬러 팔레트

```css
/* 베이스 */

--bg-secondary: #fafaf9;
--text-primary: #1a1a1a;
--text-secondary: #6b6b6b;
--text-tertiary: #a0a0a0;
--border: #e8e8e6;

/* 여성 (핑크 계열) - 메인 포인트 */
--pink: #f47b9b; /* 소프트 로즈 */
--pink-dark: #c2185b; /* 진한 핑크 (텍스트) */
--pink-pastel: #ffeef3; /* 파스텔 핑크 (배경) */

/* 남성 (블루 계열) */
--blue: #6b9bd8; /* 소프트 인디고 */
--blue-dark: #2c5282; /* 진한 블루 (텍스트) */

```

### 컬러 사용 비율

- 화이트: 70% (메인 배경)
- 파스텔: 20% (섹션 구분, 부드러운 강조)
- 블랙: 8% (텍스트, CTA)
- 핑크/블루: 2% (포인트만)

### 컬러 사용 룰

- **메인 화면**: 핑크 위주 (서비스 메인 컬러)
- **답변 입력**: 사용자 성별에 따라 핑크/블루 액센트
- **결과 화면**: 두 사람 비교 시 핑크 vs 블루 페어로 활용 (이게 핵심!)
- **파스텔은 한 섹션에 한 톤**: 섞지 말 것
- **파스텔 배경엔 진한 동계 텍스트**: 검정 X (예: 핑크 파스텔엔 #C2185B)

## ⚙️ 핵심 로직

### 심플 버전 (룰 기반, AI 없음)

```javascript
// 1. 궁합 점수 계산
function calculateMatchScore(answersA, answersB) {
  const totalDiff = answersA.reduce(
    (sum, a, i) => sum + Math.abs(a - answersB[i]),
    0,
  );
  const maxDiff = answersA.length * 3; // 4지선다 최대 차이 3
  return Math.round((1 - totalDiff / maxDiff) * 100);
}

// 2. 유형 분류 (8가지)
// 3개 축: 청결도, 계획성, 활동시간
function classifyType(answers) {
  const cleanScore = answers[0] + answers[1] + answers[2]; // 위생 문항
  const planScore = answers[6] + answers[7]; // 정리 문항
  const timeScore = answers[8]; // 아침/저녁

  return {
    clean: cleanScore < 6 ? "tidy" : "relaxed",
    plan: planScore < 4 ? "planner" : "spontaneous",
    time: timeScore < 2.5 ? "morning" : "night",
  };
}

// 8가지 유형 매핑
const TYPES = {
  "tidy-planner-morning": "새벽의 정리왕",
  "tidy-planner-night": "야행성 깔끔러",
  "tidy-spontaneous-morning": "자유로운 청결러",
  "tidy-spontaneous-night": "밤의 결벽주의자",
  "relaxed-planner-morning": "부지런한 자유러",
  "relaxed-planner-night": "계획적인 게으름러",
  "relaxed-spontaneous-morning": "햇살 자유러",
  "relaxed-spontaneous-night": "느긋한 야행성",
};

// 3. 잘 맞음 / 부딪힘 추출
function extractInsights(answersA, answersB) {
  const goodMatches = [];
  const conflicts = [];

  answersA.forEach((a, i) => {
    const diff = Math.abs(a - answersB[i]);
    if (diff <= 1) goodMatches.push({ index: i, diff });
    if (diff >= 2) conflicts.push({ index: i, diff });
  });

  return { goodMatches, conflicts };
}
```
